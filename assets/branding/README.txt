LOGO FACULTATIF DE CLAN RENARD
==============================

Tu peux placer le logo du serveur à cet emplacement :

    assets/branding/clan_renard_logo.png

Format conseillé :
- PNG transparent ;
- image carrée ;
- au moins 512 × 512 pixels ;
- sans grande marge autour du renard.

Si aucun logo n'est présent, le calendrier fonctionne quand même :
Pillow dessine automatiquement un emblème de renard stylisé.

Tu peux remplacer le logo après le déploiement puis envoyer la
modification sur GitHub. Render redéploiera automatiquement le bot.
